# Ask the Cosmos

A space tutor chatbot. For each question it searches NASA's public Image & Video Library,
gives the results to an LLM as reference material, and answers at the reader's chosen level
with links back to the NASA sources.

Settings (Streamlit secrets): `LLM_API_KEY`, `LLM_MODEL`, optionally `LLM_BASE_URL`, `NASA_API_KEY`.
